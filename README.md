# Experimental Portfolio — Noah

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder, then save.
4. GitHub Pages will publish the site at:

   https://wonka15.github.io/Experimental-Portfolio-Noah-/

GitHub's Pages documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Before sharing publicly

- Confirm the displayed name, email address, LinkedIn URL, and project descriptions.
- Add real project screenshots/renders to replace the graphic placeholders.
- Add a résumé PDF only if you want it public; link it from the contact section.
- Add the Mac Paint repository and live demo links when available.
- Check every project claim against what is actually implemented and tested.

## Project structure

- `index.html` — complete site, styles, project data, and interactions.

The site uses no external libraries. Project filters and case-study dialogs work on desktop, tablet, and mobile layouts.
