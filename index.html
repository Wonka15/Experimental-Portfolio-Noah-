Selected work

Luma Glass

A translucent, iOS-inspired interface theme for the Miyoo Mini handheld running Onion OS. Designed around a compact 640×480 display.

Problem: Make a small handheld menu feel spacious and contemporary without losing legibility.

Process: Explore grid, list and dock layouts; tune type and spacing against the device's screen; develop a dark variant.

Result: A theme used on real hardware, with constraints tested at the size that matters.

Find the project on GitHub ↗

Mac Paint

A browser-based drawing studio inspired by classic Mac software, with canvas drawing, SVG shapes, shape building and frame-by-frame animation.

Problem: Bring the directness of a classic paint program together with modern vector tools.

Process: Build feature-by-feature with JavaScript, Canvas and SVG, using AI as a coding partner and reviewing each iteration.

Result: An open-source browser tool with PNG export and a codebase structured for continued learning.

Source code ↗

TI Datamath

An interactive 3D tribute to a 1970s Texas Instruments calculator.

Problem: Static photos cannot communicate the feel and physical details of an object.

Process: Build a procedural model and walnut studio scene, add working keys, a red LED display, generated click sounds, a battery bay, AR/VR modes and a 2D fallback.

Result: A live, install-free experience for desktop and mobile. It remains a first pass, with model details still being checked against references.

Live project ↗Source code ↗

3D Studies

A collection of Blender studies: a cityscape, a space scene and a classic donut.

Problem: Learn how lighting, materials and composition change the mood of a scene.

Process: Build each scene through iterative modeling, material work and lighting experiments.

Result: Three finished renders and a growing foundation in 3D composition.

About

Hi, I’m Noah. I care about interfaces that feel obvious the moment you touch them. I got here through 3D modeling, retro hardware and a lot of tinkering. I use AI as a build partner: I break ideas into small steps, direct the implementation, test what comes back and keep iterating. I enjoy combining visual design with hands-on experimentation, especially when an old idea can be made useful in a new way.

Skills: UI/UX design and prototyping (Figma); 3D modeling (Blender, Maya, Roblox Studio); HTML, CSS and JavaScript; creative coding and AI-assisted development.
